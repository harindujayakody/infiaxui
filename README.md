# Infiax UI

An open-source, ultra-minimal, high-precision React Component Library and documentation platform built with **Shadcn UI**, **Tailwind CSS**, and **Geist Sans**.

Inspired by `ui.shadcn.com`, `magicui.design`, and `ui.aceternity.com`.

## Features

- **Exact Slate & Black Palette**: Pure `#0A0A0A` page surfaces, `#161616` cards & elevated containers, and `#262626` borders.
- **Seamless Light & Dark Theming**: Dynamic theme switching with persistent CSS variables and Tailwind support.
- **Geist Sans Typography**: Official typography styles extracted via Peek with exact scales (`type-h1`, `type-h2`, `type-heading`, `type-body`, etc.).
- **57+ Canonical Components**: Full component catalog, installation commands, TypeScript primitives, and live interactive previews.
- **Interactive Timeline Menu**: Smooth scrolling table of contents with ScrollSpy tracking and sticky header offsets.
- **Action Toolbar**: Split pill button (`Copy Page | ⌵`) with copy options and quick previous/next squircle arrow navigation.
- **Fast Search Modal**: `⌘K` command palette with instant search and CLI command preview.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
