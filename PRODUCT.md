# PRODUCT.md — Aether UI

## Vision
Aether UI is an elite React & Next.js Component Library and Design Platform inspired by the craft of Aceternity UI, Magic UI, and Shadcn UI. It empowers developers and designers to build cinematic, accessible, and high-performance interfaces through copy-paste ready, animated components with zero vendor lock-in.

## Target Audience
- Frontend developers, full-stack engineers, and product builders seeking out-of-distribution UI craft.
- Founders building SaaS dashboards and high-conversion landing pages.
- Teams migrating to Shadcn-style headless token architectures.

## Core Pillars
1. **Interactive Component Showcase**: Live, interactive previews of micro-interactions (e.g. Image Generation Loader, Chromatic Shader, Bento Grids, Glowing Border Buttons, 3D Pin Cards).
2. **First-Class Developer Experience**: One-click CLI commands (`npx shadcn@latest add ...`), code syntax inspection, and manual installation guides.
3. **Comprehensive Admin & Design System Dashboard**: Metrics on component usage, interactive theme token switchers, and component registry management.
4. **Impeccable Craft**: High-contrast typography, refined surface depths, smooth framer-motion physics, and dark-mode-first aesthetic with seamless light-mode parity.
